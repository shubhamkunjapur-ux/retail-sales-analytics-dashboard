# 🛍️ Retail Sales Analytics Dashboard

An interactive **Retail Sales Analytics Dashboard** built using **Python, Streamlit, Pandas, NumPy, and Plotly**.

## 📊 Features
- Sales and profit analysis
- Revenue by category and region
- Monthly sales trends
- Customer and product analysis
- Profitability and discount analysis
- Payment and order status analysis
- Interactive filters
- Dynamic business insights
- Filtered data download

## 🛠️ Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
